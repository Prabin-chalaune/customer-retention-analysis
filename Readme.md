# Customer Retention Analysis
This project uses the **Online Retail II dataset** from **UCI/Kaggle** to analyze customer behavior, retention, churn, customer lifetime value, and marketing performance.

## Project Overview
The project covers:
- **Exploratory Data Analysis (EDA):** Understand customer behavior, sales trends, and product performance.
- **Cohort Analysis, Retention Matrix & Churn Curves:** Track customer retention over time and visualize churn patterns.
- **RFM Scoring & Customer Segmentation:** Segment customers using Recency, Frequency, and Monetary values, along with KNN clustering, to identify high-value and loyal customer segments.
- **Probabilistic CLV Modelling:** Forecast future customer value using **BG/NBD** for purchase frequency and **Gamma-Gamma** models for monetary value.
- **Marketing ROI Analysis & Channel Attribution:** Simulate acquisition channels, calculate Customer Acquisition Cost (CAC), measure incremental uplift, and compute ROI for each channel.
- **Automated PowerPoint Dashboards & Visualizations:** Generate presentation-ready slides featuring cumulative revenue curves, CLV distributions, retention charts, and customer segmentation insights.

## Key Features
- **Cohort Analysis:** Track customer retention over time and visualize churn trends.
- **RFM Segmentation:** Identify high-value and loyal customers.
- **Probabilistic CLV Modelling:** Forecast future customer value using BG/NBD and Gamma-Gamma models.
- **Marketing ROI Analysis:** Calculate CAC and ROI, and simulate incremental uplift tests.
- **Automated Dashboard & PPTX:** Generate presentation-ready figures and PowerPoint slides programmatically.
- **Interactive Visualizations:** Create interactive Plotly charts for cumulative revenue, retention curves, and customer segments.
